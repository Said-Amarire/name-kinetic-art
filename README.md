# Name Kinetic Art

A simple, static interactive page built with HTML, CSS, and vanilla JavaScript that renders text into a particle-based canvas with smooth cursor interaction and a clean input modal.

## Live Demo
[View Live Demo](https://name-kinetic-art.vercel.app)

## Features
- **Interactive Canvas**: Text rendered as particles that react to mouse and touch movements.
- **Custom Name Input**: A clean button and modal to input and display a custom name via URL parameters.
- **Self-Hosted Typography**: Uses local font assets for complete independence.
